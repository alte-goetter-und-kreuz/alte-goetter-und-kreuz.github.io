# Zwischen alten Göttern und Kreuz

Ein unabhängiges populärwissenschaftliches Online-Magazin über Christianisierung, germanische Religion, Zeichen, Runen, Archäologie und religiösen Wandel.

Die Website wird als statische Website über GitHub Pages veröffentlicht: https://alte-goetter-und-kreuz.github.io/

Beiträge unterscheiden zwischen archäologischem Befund, historischen Quellen und Forschungsinterpretation. Für die redaktionelle Einordnung siehe [Quellen & Methodik](https://alte-goetter-und-kreuz.github.io/quellen/).
